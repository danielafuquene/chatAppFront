# Governance Rules

## Approval Required

Before modifying any file:

- Analyze the codebase.
- Create an implementation plan.
- Present the plan.
- Wait for user approval.

Never edit files before approval.

## Allowed Before Approval

- Read files.
- Analyze architecture.
- Detect dependencies.
- Create plans.

## Forbidden Before Approval

- Create files.
- Edit files.
- Delete files.
- Rename files.
- Install packages.
- Execute migrations.

## Dependency Policy

Always ask approval before adding dependencies.

## Refactoring Policy

Always provide impact analysis before major refactors.
